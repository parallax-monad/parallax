# BE-041 controlled Camelot V3 target scenarios

This directory contains controlled, offline feasibility records for the Arbitrum Sepolia × Camelot V3 entry point.

The records are intentionally not real pair/pool acceptance evidence. Token pair and pool values remain `unconfigured`; quote and unsigned transaction construction are replaceable seams; no provider credential, final Evidence schema, or Receipt schema is present.

Use the runtime adapter and its injected seams for deterministic tests. Do not promote these records to BE-047 real pair/pool/quote acceptance.
